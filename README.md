# PROJECT 4 — REACT-O-BALL

**Name:**
React-o-ball

**Context:**
1st Semester — Structured Programming Project

React-o-ball is a game inspired by **DX-Ball**, but introduces an elemental reaction system.

Both bricks and the ball can contain different natural elements.

Possible elements include:

* Fire
* Water
* Wind
* Ice
* Electricity

Instead of bricks simply breaking normally, elements can interact with one another and cause different reactions.

Examples include:

Water + Electricity → electricity can spread

Wind + Fire → can intensify or influence fire behavior

Ice + Water → elemental interaction

Fire + Electricity → explosive reaction

The concept combines a classic brick-breaking game with an experimental elemental interaction system.

Project description suggestion:

“A DX-Ball-inspired game that replaces conventional brick interactions with an elemental reaction system. Fire, water, wind, ice, and electricity interact dynamically, turning a simple brick-breaking mechanic into a more experimental strategy-driven experience.”

Emphasize the creativity of the gameplay concept.

The original project was developed during the 1st semester as a Structured Programming project.
